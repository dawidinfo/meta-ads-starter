# Meta-Ads-Starter – Claude-Skill von Dawid Przybylski · KI-Kodex.io

Ein kostenloser Claude-Skill, der dich Schritt für Schritt durch Meta-Lead-Kampagnen führt – von 50 € bis 10.000 € Werbebudget am Tag.

**Was der Skill kann**
- Passende Struktur für dein Tagesbudget (4 Budgetstufen)
- Einstellungen Klick für Klick (Lead-Kampagne, Test-Kampagne)
- Aufbau einer starken Anzeige: Hook auf 4 Ebenen, 10 Hook-Typen
- Testen mit dem 3-Slot-System, Abschalt-Regeln
- Auswertung: Kennzahlen, Diagnose, Quote schlechter Leads
- Ab wann sich Nurture lohnt, die häufigsten Fehler

Der Skill arbeitet nur lesend: Er legt nichts in deinem Werbekonto an und löscht nie etwas.

## Installation

**Claude (App / claude.ai)**
1. **[⬇ meta-ads-starter-dawid.zip herunterladen](https://github.com/dawidinfo/meta-ads-starter/raw/main/meta-ads-starter-dawid.zip)** (nicht entpacken).
2. In Claude links in der Seitenleiste **Anpassen → Skills** öffnen, auf **+** klicken und die ZIP hochladen.
3. Den Skill in der Liste per Schalter **aktivieren** – hochgeladen ist noch nicht aktiviert.
4. Neuer Chat: „Meta-Ads-Starter: Mein Budget ist 100 € am Tag. Ich verkaufe [Angebot] für [Preis]. Landingpage: [Link]. Ich will höchstens [X] € pro Lead zahlen.“

> Skills-Menü ausgegraut oder nicht da? **Einstellungen → Funktionen → „Codeausführung und Dateierstellung“** einschalten. Skills gibt es in den bezahlten Claude-Tarifen (Pro, Max, Team, Enterprise).

**Claude Code**
```bash
git clone https://github.com/dawidinfo/meta-ads-starter.git
cp -r meta-ads-starter/skills/meta-ads-starter-dawid ~/.claude/skills/
```

## Daten für die Auswertung
Ohne Werbekonto-Verbindung einfach einen Screenshot oder CSV-Export aus dem Werbeanzeigenmanager hochladen (Ebene Anzeigen, letzte 7 und 30 Tage).
